# أجندة المستشار

أجندة إلكترونية لمستشاري هيئة قضايا الدولة: الجلسات والمتابعات والأحكام في مكان واحد، بديلاً عن شيت الإكسيل.

## المميزات
- **اليوم:** جلسات اليوم والأسبوع، جلسات فاتت بلا قرار، متابعات مستحقة، مواعيد طعن قريبة.
- **رول الجلسات:** يوم/أسبوع مجمَّع بالمحكمة والدائرة، مع طباعة؛ والأيام الماضية تعرض ما تقرر (أرشيف الجلسات).
- **تسجيل قرار الجلسة:** تأجيل، حجز للحكم، حجز للتقرير، حكم، شطب — مع اقتراح المواعيد على يوم انعقاد الدائرة وسجل كامل لكل دعوى.
- **ترحيل مجمّع** وتحديد جماعي، ربط بدائرة، أرشفة وإلغاء حفظ.
- **القضايا:** المتداولة، الشعبة، تحت الرفع، المشطوبة، الأرشيف؛ بحث بالعربي وبالرقم (152/2024).
- **الأحكام:** صالح/ضد، رقم القيد، ميعاد الطعن (تقديري)، قرار الطعن.
- **المرفقات** (مذكرات، رأي، صورة الحكم) وتقرير كامل للدعوى للطباعة.
- **الإحصائيات** لأي فترة.
- **الأدوات:** حاسبة المواعيد الإجرائية، حاسبة الفوائد القانونية، تفقيط المبالغ، حافظة مستندات، قوالب خطابات.
- **الإكسيل:** استيراد شيت الأجندة وتصدير بنفس الأعمدة.
- **تقويم جوجل:** مزامنة الجلسات والمتابعات ومواعيد الطعن مع تنبيهات على الموبايل.
- كل مستشار له حسابه وبياناته فقط (Supabase RLS)، والدخول بالبريد أو بحساب جوجل.

## التشغيل
```bash
npm install
cp .env.example .env   # ثم املأ القيم
npm run dev
```

## قاعدة البيانات
نفّذ ملفات `supabase/` بالترتيب في SQL Editor: `schema.sql` ثم `002_profiles.sql` ثم `003_phase1.sql`.

> المواعيد والحسابات القانونية في البرنامج تقديرية وتعرض القاعدة العامة فقط؛ راجع النص الساري قبل الاعتماد عليها.
